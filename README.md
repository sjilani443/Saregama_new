# 🎵 Saregama – Web Music Player

A dynamic and responsive web-based music player designed for streaming and exploring music. It supports features like top charts, trending playlists, personalized recommendations, and artist-specific collections.

![Screenshot](./Screenshot%202024-05-28%20102029.png)

## 📸 Demo

> 🖥️ Localhost view shown in the screenshot. Deployment link coming soon.

## ✨ Features

- 🎧 Display of trending songs, top charts, and artist essentials
- 🔎 Search functionality for music, albums, and artists
- 👤 User profile section and personalized greeting
- 🎨 Responsive UI with modern dark theme
- 🎵 Playlist and podcast navigation sidebar
